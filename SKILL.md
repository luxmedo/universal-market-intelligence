# Universal Market Intelligence

When asked to analyze a market, product, niche, or business idea:

1. Define geography, buyer, product, business model and sales channel. Ask at most one essential clarification.
2. Discover legal, available sources using references/sources.md. Never claim access to an API without verifying credentials and permissions.
3. Analyze demand, seasonality and growth; distinguish relative search interest from actual sales.
4. Compare 5+ competitors when data permits, including price, positioning, and sources.
5. Analyze customer needs, distribution channels, SEO and customer acquisition.
6. Build conservative, base and optimistic unit economics with scripts/unit_economics.py.
7. Evaluate licensing, marketplace policies, payment, operational and privacy risks.
8. Score the opportunity with references/scoring.md and identify missing evidence.
9. Recommend a 30-day low-cost validation experiment with pass/fail criteria.
10. Present a report using templates/report.md with source URLs, dates and confidence.

## Rules
- Never invent sales, revenue, search volumes, traffic, conversion rates or API integrations.
- Label verified measurements, third-party estimates, and hypothetical assumptions separately.
- Respect terms of service, rate limits, privacy and access controls. Never bypass CAPTCHAs or scrape authenticated data without permission.
- If an API is unavailable, use lawful alternatives or user-provided exports; report missing evidence.
- Do not automatically spend money, publish, or create accounts.
- A resale license does not automatically permit reselling on Etsy; independently verify current marketplace policy.
- Research is advisory and does not guarantee profitability.

## Example
"Analyze crochet pattern PDFs in the US, compare competitors, calculate margins, and recommend a launch test."

## Mandatory visual results stage
After every completed market study, execute the Visual Intelligence workflow in references/visual-reporting.md.
Produce a readable dashboard (HTML with embedded SVG charts, or PNG/PDF when the environment supports rendering) alongside the written report. For numerical data, render actual data-driven charts, not an AI-generated illustration of charts. If no file rendering tools are available, present clearly formatted Markdown tables and chart-ready datasets, and explain the limitation. Do not claim a graphic was generated unless the file exists.
